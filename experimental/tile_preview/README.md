cuda-tile-preview
=================

Preview APIs for [cuTile Python](https://github.com/nvidia/cutile-python) (`cuda-tile`).

The APIs in this package are experimental. They live in the `cuda.tile_preview` namespace and
may change or be removed in any release without notice.

Installation
------------
```
pip install cuda-tile-preview
```

This also installs `cuda-tile`.
